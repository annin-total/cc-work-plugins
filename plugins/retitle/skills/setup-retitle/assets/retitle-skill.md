# セッションタイトルの付け直し

会話全体を踏まえ、**いま取り組んでいるタスク**を表す要約を 1 つ決める。最初の依頼ではなく、現在の趣旨を優先する。
引数（`$ARGUMENTS`）が空でなければ、それを要約としてそのまま使う。

要約の形：名詞句。対象の固有名詞（ツール名・機能名・ファイル名など）を入れ、「設計」「調査」のような汎用語だけで済ませない。
英語の技術用語はカタカナにせず英語のまま書く。全角なら 15 字、半角英数なら 30 字程度を目安にする（表示幅 40 を超えた分はスクリプトが切る）。ブランチ名・「 · 」・記号・引用符は入れない（ブランチはスクリプトが付ける）。

次を実行する。

```bash
"{{PYTHON}}" "{{SCRIPT}}" --set "${CLAUDE_SESSION_ID}" "<要約>"
```

シェルが PowerShell のときは、先頭に `& ` を付けて実行する。

出力された 1 行（ブランチ付き）がタイトルになる。反映は UserPromptSubmit hook が次の送信時に行うため、即時には変わらない。
返答は次の 2 行だけにする。`<タイトル>` には出力された行をそのまま入れる。

```
「<タイトル>」を次の送信で反映します。
すぐ変えるなら: /rename <タイトル>
```
